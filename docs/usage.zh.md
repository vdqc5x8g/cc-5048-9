# 转头重投影 · 空间音画视窗（使用说明）

## 图形入口（主要交付）

在仓库根目录启动零依赖静态服务后，用支持 **WebGL2** 的浏览器打开：

```bash
node cli/serve.js          # 默认 http://localhost:8080/
# 或指定端口
node cli/serve.js --port 9000
```

图形入口页面为 **`index.html`**（服务启动后访问根路径 `/` 即自动加载）。
页面是纯静态 ES 模块实现，必须通过 http 服务访问（`file://` 下浏览器会拒绝加载模块）。

> 命令行仅提供静态服务与数值表等辅助功能；重投影画面与边界完全由页面中的
> WebGL2 片段着色器在每个显示帧实时计算，不存在固定图片/固定数据冒充。

## 界面布局

页面自上而下：

1. **三视窗（同步展示同一呈现时刻）**
   - ① 未经修正的延迟画面：直接显示按较早姿态 `t_s` 渲染的旧帧。
   - ② 迟到修正帧：在呈现时刻 `t_p` 用最新姿态对旧帧做**旋转重投影**；
     旧纹理覆盖不到的区域以红色斜纹标记（或切换为声明式边缘钳取），黄色描线为可用视野边界。
   - ③ 参考帧：以 `t_p` 最新姿态**直接渲染**的对照画面，标注为离线诊断用途，
     不计入演示渲染管线，也不用于提高原始渲染频率。
2. **时刻记录区**：`t_s / t_r / t_p` 三时刻的时间轴可视化与逐帧表格
   （姿态采样时刻、渲染时刻、呈现时刻、端到端延迟、Δyaw、角速度）。
3. **误差与边界区**：修正帧/旧帧相对参考帧的 RMS 色差、越界占比、实测渲染频率，
   以及误差随角速度变化的曲线图。
4. **控制台**：播放控制、轨迹参数、延迟/渲染节奏、越界处理模式、空间音频、CSV 导出。

## 控制台按钮与滑块（均驱动实时重投影）

| 控件 | 作用 |
| --- | --- |
| 暂停 / 继续、单步 +33 ms、重置轨迹 | 控制可重复的正弦 yaw 仿真时钟 |
| 振幅 / 频率 / 相位滑块 | 修改 `yaw(t)=A·sin(2πft+φ)`，立即生效且可复现 |
| 角速度扫描（10 s） | 频率自动爬升的实验轨迹，用于观察误差随角速度变化，10 s 自动停止 |
| 运动-光子延迟滑块、0/50/100/200 ms 预设 | 选择显示时回看的旧帧（0–300 ms） |
| 原始渲染间隔滑块（33–200 ms） | 固定的场景渲染节奏；**重投影不改变该节奏** |
| 采样→渲染固定间隔 | `t_s = t_r − Δ_SR`，区分姿态采样时刻与渲染时刻 |
| 斜纹标记 / 边缘钳取 | 越界区域处理切换；钳取模式保留边界描线且不声称正确重建 |
| 开启空间音 | 世界 +X 固定声源（HRTF），听者朝向随最新姿态同步，转头可听声像偏移 |
| 导出 CSV / 清空记录 | 导出逐帧时刻与误差记录 |

## 推荐实验流程

1. 默认参数（45° 振幅、0.8 Hz、100 ms 延迟、66 ms 渲染间隔）运行，对比三视窗。
2. 观察修正帧中斜纹/边界随转头速度扩大；切到“边缘钳取”对比两种边缘处理。
3. 点击“角速度扫描”，结束后查看误差-角速度曲线：修正帧 RMS 显著低于旧帧，
   越界占比随角速度上升。
4. 把延迟调到 200 ms，重复实验，观察延迟与角速度共同放大越界区域。
5. 开启空间音，在左右转头时确认声像随最新姿态移动。
6. 导出 CSV，与 `node cli/atw-cli.js error-table` 的数值边界核算交叉对照。

## 后端迁移核对面板（页面内）

控制台上方的“图形后端迁移核对”面板提供交互式核对入口（CPU 软件后端，
与 `cli/migrate-verify.js` 同一份代码）：

- **工程轨迹**：旧工程（仅偏航）/ 新工程（偏航+俯仰+滚转）切换。
- **栅栏闸门**：手动模式下渲染帧默认不放行，用“放行一个迟到栅栏”单步推进；
  配合 **wait / discard 呈现策略** 可看到等待挂起（保持上一帧）与丢弃过时姿态
  回退已就绪帧的不同可见结果。
- **显示眼别**：左眼/右眼切换，每只眼纹理带独立眼别编码。
- **翻转注入**：纹理原点翻转或矩阵翻转时，下方角标报告会指出哪只眼的哪个角
  先错；无翻转对照组四角身份必须全部正确。
- **读取旧记录（仅帧号）**：演示只有 `frameNo` 的旧记录如何映射到环形槽，
  槽已复用时报告 `recycled` 而不读取当前槽内容。
- **导出最小重放 JSON**：只含事件与角标/帧号读回，不含整幅纹理。

环形槽仅 2 个，第 3 帧起即可观察纹理复用与代际守卫。方法细节见
`docs/migration.zh.md`，无头核对见 `docs/cli.zh.md` 第 3 节。

## 适用范围声明

- 本初版只修正**头部旋转**（演示轨迹为 yaw；数学实现使用四元数，pitch/roll 同构）。
- **不**宣称修复头部平移、场景物体独立运动造成的视觉误差；这类误差在画面中原样保留。
- 越界区域没有任何已渲染样本可供重建，只能标记或按声明方式钳取边缘，不是“正确重建”。

## 浏览器要求

Chrome/Edge/Firefox 任一支持 WebGL2 与 `AudioContext` 的现代版本。
空间音频需要用户点击按钮后才会启动（浏览器自动播放策略）。
